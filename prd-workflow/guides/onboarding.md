# PRD Workflow 用户引导 — 如何配置你的个人参考知识库

> 欢迎使用 PRD Workflow！本引导将帮助你配置个人参考知识库，让 PRD 生成更精准。

---

## 为什么要配置个人参考知识库？

PRD Workflow 内置了通用 PRD 模板，可以生成格式规范的 PRD 文档。但如果你有：

- **历史 PRD 文档**（风格统一的过往文档）
- **公司 PRD 规范**（企业级标准格式）
- **特定产品线的参考模板**（如空调/冰箱/洗衣机专用格式）

配置参考知识库后，PRD Workflow 会**优先参照你的模板**生成文档，确保输出风格与你期望的一致。

---

## 如何提供参考材料？

支持以下 **6 种格式**，任选其一即可：

### 1. 飞书文档链接（推荐）

直接发送飞书文档 URL 给 Agent：

```
参考这份 PRD：https://xxx.feishu.cn/docx/xxx
```

### 2. 本地 Markdown 文件

发送 `.md` 文件给 Agent，或在聊天中粘贴 Markdown 内容。

### 3. Word 文档

发送 `.docx` 文件给 Agent，系统会自动解析。

### 4. PDF 文档

发送 `.pdf` 文件给 Agent，系统会自动提取文本内容。

### 5. Excel 表格

发送 `.xlsx` 或 `.xls` 文件给 Agent，系统会解析所有 Sheet。

### 6. 图片

发送包含 PRD 格式的截图给 Agent，系统会 OCR 识别文字。

---

## 参考材料要求

### 最低要求（任一即可）

- ✅ 一份完整的 PRD 文档（含章节结构）
- ✅ 一份 PRD 模板（含表格格式、字段定义）
- ✅ 一份功能清单（含功能编号、描述）

### 最佳效果

提供包含以下内容的参考材料：

| 内容 | 说明 |
|------|------|
| 产品概述格式 | 产品信息的表格格式 |
| 功能矩阵格式 | 功能对比表的列定义（编号/功能/说明/PK列/备注） |
| 附录格式 | 快速索引表、开关机状态表、互斥规则表的样式 |
| 版本记录格式 | 文档版本追踪的表格样式 |

## 使用示例

### 示例 1：首次使用（无参考材料）

```
用户：帮我写一个空调的 PRD
Agent：📖 检测到您尚未配置个人参考知识库，将使用内置通用模板。
        如需更精准的风格匹配，请提供参考材料...
```

### 示例 2：提供参考材料后

```
用户：参考这份 PRD：https://xxx.feishu.cn/docx/xxx，帮我写一个新产品的 PRD

        👀 我理解您的需求：...
```

### 示例 3：提供本地文件

```
用户：[发送文件] 参照这个模板，帮我生成冰箱的 PRD
Agent：已解析参考文件，将使用该模板格式。
        👀 我理解您的需求：...
```

```
用户：参考模板更新了，用这份：https://xxx.feishu.cn/docx/xxx
Agent：已更新参考模板，后续 PRD 生成将使用新版本。
```

## 常见问题

### Q: 不配置参考知识库就不能用吗？

A: 可以用。内置通用模板会确保 PRD 有统一的基本格式。但配置后生成结果会更符合你的期望。

### Q: 参考材料会被泄露吗？

A: 不会。参考材料仅存储在你的本地环境中，用于 PRD 生成时作为格式参照，不会被共享或上传。

### Q: 可以同时使用多个参考模板吗？

A: 可以。提供多份参考材料时，系统会综合分析各模板的结构特征，生成最合适的 PRD。

### Q: 参考材料有格式要求吗？

A: 没有严格格式要求。PRD Workflow 会自动识别结构特征（章节、表格、层级关系），并提取可用的格式信息。
