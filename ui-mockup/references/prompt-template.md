> 基于 RASCEF（Role-Action-Steps-Context-Examples-Format）+ Atomic Prompting（Organism-Molecule-Atomic-Parameters）双层框架设计。

## 各节填写指南

### 角色设定（RASCEF-Role）
- 始终定义为"资深 UI/UX 设计师"
- 强调"增量式设计"和"保持未改动区域一致"
- 这是让 AI 进入正确设计思维的关键，不要省略

### 页面定位（Atomic-Organism）
- 写清楚产品路径（面包屑）
- 一句话说清页面做什么
- 描述整体视觉风格（配色体系、设计系统、主题）

### 现有页面结构（Atomic-Molecule）
- 按区域（Region）划分，每个区域一个子标题
- 列出核心字段和控件类型
- **重点标注改动区域**，用 ⚠️ 标记
- 不变区域可以简要描述，改动区域要详细

### 新增 UI 改动（Atomic-Atomic）
- 每个改动独立一个子标题
- **必须有 ASCII 线框图**——这是最有效的视觉传达方式
- 交互细节要覆盖 5 种状态：默认、展开/收起、校验、加载、空数据
- 位置描述用参照物（"在 XX 下方"），不用绝对坐标

### 卡片视觉规范（Atomic-Parameters）
- 给出**具体数值**，不要只写"与现有一致"
- 配色用 hex 色值
- 字号用 px
- 阴影用 CSS 语法
- 这些参数是防止风格漂移的硬约束

### 最终页面效果预期
- 完整的 ASCII 线框图，覆盖整个页面
- 用双线边框 `╔══╗` 标注改动区域
- 用 `（不变）` 标注不变区域
- 这是 AI 理解整体布局的关键输入

### 硬性约束
- 至少 4 条，推荐 5-6 条
- 用 ⛔✅🎨📐🚫🖼️ emoji 前缀增强可读性
- 第一条必须是"不变区域禁止修改"
- 最后一条指定输出格式和分辨率

### AI 绘图工具参数
- 根据实际使用的工具填写
- Midjourney：写 `--ar`、`--style`、`--v` 参数
- DALL-E 3：写自然语言风格描述
- Stable Diffusion：写 positive/negative prompt + 权重
- 通用关键词：`high fidelity UI mockup, pixel-perfect, professional`
- 通用排除：`blurry, low quality, cartoon, 3D render, watermark`
